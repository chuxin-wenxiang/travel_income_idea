# 上海国内机会试跑（2026-10-29）

## 结论与范围

本轮跑通了公开发现、原文核验、用户匹配、保存、预算计算的软件流程，**没有跑通雇主确认、接单、履约、到账**。没有发现能向本次普通游客画像推荐出发的已核验机会；不等于上海没有机会。没有登录求职平台、加入群聊、发送报名或联系商家。

当前国内自动实时数据源数量为 **0**。本版交付的是可用的本地人工核验流程，不能称为“三类实时机会已自动接通”。真正建立持续供给仍需要发布方授权的数据接口/供稿，或用户逐条在原站核验。不会用国外远程职位填充国内结果。

假设用户：非学生，无专业摄影交付能力、无自备相机；2026-11-05 至 11-08 在上海停留，每天最多工作 6 小时，可接受换宿。此画像不是项目所有者个人资料。

## 可复现步骤

1. `npm start`，打开 `/web/domestic.html`，通过来源入口在原站搜索。
2. 填写上述假设画像，逐条按原文整理要点；未知项留空/未知。日期未写年份时勾选日期不确定，不拿页面截止日代替工作日。
3. 点击核验。摄影样本应显示技能不匹配，以及旧帖、工作日/工时/资格/收费与报名入口待核实等原因。只看标签“兼职”不足以推荐。
4. 保存到工作台。该记录仍是待核验，确认订单数为 0。下载核验记录可保留依据与下一步。
5. 按以下假设试算；不要将报价当成已确认订单。用完成后的实际到账/支出栏记录事实，本轮没有实际到账记录。

无浏览器也可复现摄影筛选：

```sh
node scripts/domestic.mjs data/shanghai-review.json
npm test
```

`data/shanghai-review.json` 是带来源的人工核验案例，绝不是实时接口响应。软件测试中的正向匹配案例是合成测试数据，不展示为实际机会。

## 预算结果（全部为假设，不是实时旅游报价）

往返交通 500 元，3 晚住宿每晚 180 元，4 天餐饮每天 80 元，其他 200 元，总支出 **1560 元**。预算 2500 元，无需靠未来订单垫付；未确认收入与住宿减免均为 0，旅行净现金变化 **-1560 元**，现金预算剩余 **940 元**。

即便仅作敏感性分析假设获得 1 次 400 元摄影收入、暂不增加其他成本，净变化仍为 -1160 元；本画像没有相应能力，不能将此情景当作可执行建议。机会不足时，应缩短行程/降低成本/延后出发或补齐技能，而不是为了“赚钱旅行”凑一份不成立的方案。

## 下一步供给缺口

- 旅拍：需要商家明确拍摄日期、成片规格、单次工时、作品门槛与短期结算金额；高日薪搜索页不够。
- 展会：需要主办方/用工方发布完整班次、资格、申请入口及结算条款；活动日历只能证明活动存在。
- 换宿：需要旅舍当期直接招募与店家身份，最短驻留、每日劳动、房型、费用和取消机制齐全；普通志愿服务不等于包住或有薪。
- 自动抓取：先获得允许再接接口，不以浏览器登录态、绕过验证码或他人账号作为外部用户安装条件。
