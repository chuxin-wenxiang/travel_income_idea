# 信息来源与独立使用

## 实际已接入：Jobicy 公共 Jobs API

- 官方文档：https://jobicy.com/jobs-rss-feed
- 官方接口说明：https://github.com/Jobicy/remote-jobs-api
- 接口：`https://jobicy.com/api/jobs?count=100`；无需账号、API Key 或本项目作者权限。
- 本项目只加载最近一页，最多 100 条，包含长期全职；并不覆盖国内临时工、旅拍客户或全部远程职位。
- 地区字段是就业资格限制，不是推荐旅行目的地。原币种、薪资周期保留，不转换成年旅费收入。
- 列表只保留必要字段、短摘要和原站链接，点击原站查看完整要求与申请。来源声明不移除。
- 每次用户手动加载优先使用一小时本机缓存；并发合并，不做后台定时轮询。来源可能延迟，源站文档当前说明存在发布延迟。
- 首次失败返回明确错误；缓存过期而更新失败时返回原缓存和 stale=true，保持旧读取时间，不伪装成最新数据。
- 下次重新加载不在列表中，不代表职位已关闭；本版不自动宣判职位状态。申请前必须查看原文。
- 本地缓存位于 `.cache/`，已排除 Git。第三方职位内容不因项目 MIT 许可证变成可任意再分发的数据。

2026-10-29 集成实测：项目适配器成功读取 100 条，包含原链接、地区和薪资周期。一次请求曾超时，后续成功；不能保证每个网络环境均可达。超时不会回填虚构岗位。

## 国内招募与其他来源：用户录入

用户提供 HTTPS 原文链接、原文要点、地点、截止日与核验确认，可用于旅拍、临时协作、换宿等。活动线索与明确招募分开；活动线索不能标为已确认合作。对方确认内容必填后才允许在计划中计入确认单数。

此路径不需要任何联网密钥；项目不会抓取用户粘贴的任意链接，不读取其登录状态，不代理访问付费内容。公开页面读取、自动抓取授权和数据再分发许可应分别评估。

## 尚未接入

国内活动/招募自动聚合、机票酒店实时报价、自动报名、职位关闭状态批量核查、支付、模型 API。不要将这些描述为已支持。

新增适配器应先确认公开授权、字段、访问门槛和失败行为，再实现规范化与测试。不要仅新增一个来源名称或空接口。

## 国内来源 v0.5

完整目录在 `data/domestic-sources.json`，真实案例与测试范围见 [上海试跑](shanghai-validation.md)。国内来源采用原站人工查找/本地核验，不自动请求来源网站，不携带用户登录态，也不向外发送表单正文。工多多协议限制未经授权抓取，故未实施爬虫。国内自动实时源数量为 0；没有把源站链接数量当成接入数量。
