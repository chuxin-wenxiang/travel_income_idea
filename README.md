# 旅有余 · 旅行创收工作台 v0.5

结合旅行与出行发现挣钱机会：找到事件和人群 → 明确买方与需求 → 提供商品、服务或资源 → 验证交易 → 算清成本与现金。招聘只是其中一种路径。

## 无账号启动

需要 Node.js 22+ 和 Git。没有 npm 依赖，不需要 API Key。

```sh
git clone https://github.com/chuxin-wenxiang/travel_income_idea.git
cd travel_income_idea
npm start
```

打开终端打印的 `http://127.0.0.1:4173/`。端口占用时可设置 `PORT` 环境变量。服务只监听本机。直接双击 HTML 无法使用接口和模块。

## 可以真实完成的流程

1. **录入自己的招募**：填来源链接、地点、原文要点、截止日，保存为待核验线索。可以是国内旅拍、兼职、换宿等。
2. **或加载公开职位**：无需账号调用 Jobicy 公共接口，保留地区限制、工种、原文与薪资周期；保存感兴趣的职位。它主要是远程工作，不是国内短期兼职池。
3. **跟进**：查看原文、联系对方，记录实际确认内容，再改成已确认合作。本工具不会替你报名或发消息。
4. **制定计划**：填写实际商定的每单报酬和总工时。区分计划单数与已确认单数，比较零订单、减免失效等情况，核对预算缺口。
5. **保存 / 导出**：刷新后仍保留计划，导出含来源和行动清单的 Markdown。完成后记录实收、全部支出、工作小时。

网页菜单中的“玩法与试算”保留早期 100 种灵感和 6 个演示模板，所有模板金额都未验证，不代表真实报价。

## 数据与隐私

机会、计划和实际结果保存在当前浏览器 localStorage。导出 JSON 备份后可在另一台设备恢复；恢复只合并新记录，重复来源保留本机版本。清理浏览器数据会丢失记录，请自行保管备份。备份可能包含私人工作信息，不要提交到 GitHub。

只有主动点击加载来源时，本地服务才访问 Jobicy；不会发送个人工作台记录。公开数据缓存一小时，刷新失败明确显示旧缓存或错误。来源覆盖与限制见 [sources.md](docs/sources.md)。

## 命令行与 Skill

```sh
npm test
npm run discover
npm run install:skill
# 更新已有安装（自动备份旧目录）
node scripts/install-skill.mjs --update
# 其他支持 SKILL.md 的助手，可指定目标目录
node scripts/install-skill.mjs --dest /path/to/skills/travel-income-assistant
```

安装只复制技能所需文件，不包含本机缓存、浏览器记录或密钥。不同助手对技能发现方式不同，请按宿主说明加载；技能文件本身不赠送模型或搜索服务。

AI 助手读取 [SKILL.md](SKILL.md)，可运行 `node scripts/discover.mjs` 获取公开远程职位；离线时可处理用户提供的招募信息并用 `node scripts/calculate.mjs plan.json` 测算。输入格式见 [测算规则](docs/model.md)。

## v0.5 国内机会核验（上海试点）

启动后点击“国内旅拍 / 展会 / 换宿”，或访问 `/web/domestic.html`。提供国内原站入口、本地正文核验、行程与资格匹配、保存及预算流程。未知条件不会被自动认定为符合；工作日期与申请截止日期分开。

**国内尚无获授权的实时招聘 API 接入**，当前需要用户在原站查找并手动整理；不会抓取登录后内容。Jobicy 仅作为可选远程来源。详见 [上海真实来源试跑与限制](docs/shanghai-validation.md)。本轮筛出的普通游客可推荐机会为 0，未确认收入按 0 测算。

命令行核验：`node scripts/domestic.mjs data/shanghai-review.json`。案例带历史核验时间，不作为当前招募保证。

## 先看挣钱机会，而不只看招聘

[旅行与出行挣钱机会地图](docs/opportunity-map.md)：保留原100条，新增40个细化/补充商业切口，覆盖演唱会周边、IP展商品、市集经营、赛事补给、商贸服务、商家合作、顺路委托、内容授权和资源交换。每个切口列明买方、交付物、获利机制及首先要验证的条件；数据见 `data/opportunity-map.json`。

当前网页计算器适用于服务订单，**不能直接评估预先进货的摆摊生意**。商品生意须扣除全部进货支出并单独记录剩货；公式与示例见机会地图。来源入口不等于实时接口或现成订单。
