# 旅有余 · 旅行创收助手 v0.3

让旅行更可负担：把技能、时间和真实需求转化为旅行中的收入或费用减免，保留旅行体验。

## 现在可以使用什么

- 本地网页：6 个典型演示方案，按技能筛选；可修改成本、订单与工时。
- 同时计算零接单、半数订单、计划订单情景、回本单量、预算缺口。
- 工时容量约束；住宿减免不计现金收入；导出 Markdown 方案。
- 原始 100 种玩法可搜索，历史收入区间不参与测算。
- 配套 [Skill](SKILL.md) 可供 AI 助手进行有来源的机会核验和规划。

这是可运行的决策原型。尚未接入实时招聘、交通住宿价格、模型 API、预订或支付。没有保证收入；所有默认数字均为演示假设。数据不上传，刷新清空输入。

## 本地运行

要求 Node.js 22 或更新版本，无第三方依赖。

```sh
npm start
# 打开 http://127.0.0.1:4173/web/
npm test
```

也可直接执行 `node scripts/serve.mjs` 和 `node --test tests/*.test.mjs`。

## Skill 使用

把本仓库中的 `SKILL.md`、`docs/`、`data/`、`web/engine.mjs` 与 `scripts/calculate.mjs` 保持相对目录关系，放入助手的技能目录 `travel-income-assistant/`。支持文件读取的助手也可以直接读取仓库内 SKILL.md，无需安装整个应用。

示例：我会摄影，有四天假期、2500 元预算，每天最多工作三小时，想尽量覆盖旅费。

计算器：`node scripts/calculate.mjs plan.json`。字段见 [测算规则](docs/model.md)。网页与命令行共用同一个引擎。
